Project Title  
Palindrome Checker System

Research Problem  
How can a program determine whether a word reads the same forward and backward? Many users may want a simple way to check palindromes automatically instead of manually reversing words. This project solves that problem using a stack-based approach in C++.

Motivation  
This project is important because it demonstrates how stacks and arrays can be used in real programming problems. The system reverses a word character by character and compares it with the original input to determine whether it is a palindrome.

Control Flow  
User opens the program  
User enters a word  
System stores each character into a stack  
System removes characters from the stack in reverse order  
System creates the reversed word  
Program compares the original and reversed words  
System displays whether the word is a palindrome or not
